# 性能与资源基准

脚本：`node scripts/performance-bench.ts`（结果：`reports/performance-benchmark.json`）
环境：Node v24.19.0，单机（Android 容器），SQLite 3.53.3；单次测量，无预热统计。

## 1. 冷启动

| 口径 | 结果 |
| --- | --- |
| 引擎打开（进程内，含建库/迁移/索引加载） | median **35.9 ms**（样本 40.8/34.6/32.6/35.9/38.0） |
| 进程级（node 启动 + 模块 import + 打开空库） | **466–480 ms**（3 次：474/466/480） |
| v2.0 旧测量（legacy 数据 + import） | 415 ms |

结论：打开引擎本身很快；主要固定成本是 Node 进程与模块加载。

## 2. 写入与读取

| 操作 | 规模 | 耗时 |
| --- | --- | --- |
| 批量写入 | 100 | 264.6 ms |
| 批量写入 | +400（累计 500） | 972.2 ms |
| 批量写入 | +500（累计 1000） | 1,179.8 ms |
| 读取 100 条 by id | 1000 库 | 9.0 ms |
| 100KB 文档摄入（抽取 390 drafts + 写库） | 102,864 字符 | 2,847.9 ms（extract 70.6 / write 2,777.3） |
| 10KB 文档摄入（41 drafts） | 10,499 字符 | 310.2 ms（extract 18.3 / write 291.9） |
| 一轮学习（6 任务：discover→extract→verify…） | 1 文档 | 72.2 ms |

写入主要成本：BLAKE2b(BigInt) 特征哈希 + 索引落盘；1000 条约 1.2s，属于可接受但可优化项。

## 3. 检索延迟（Top-8，60 次/模式）

| 语料 | keyword p50/p95 | vector p50/p95 | hybrid p50/p95 |
| --- | --- | --- | --- |
| 100 | 2.43 / 4.51 ms | 2.75 / 8.12 ms | 3.79 / 5.56 ms |
| 500 | 5.31 / 9.02 ms | 3.47 / 13.84 ms | 7.56 / 18.31 ms |
| 1000 | 9.40 / 13.55 ms | 4.74 / 9.79 ms | 12.23 / 16.16 ms |

关键词延迟随语料线性增长（SQL 候选 + 内存打分）；向量几乎恒定；混合是两者之和。

## 4. 重复检测：优化前后（相同脚本 / 数据 / 阈值 0.95）

| 语料 | 优化前 | 优化后 | 加速 |
| --- | --- | --- | --- |
| 200 | 866.5 ms | 51.5 ms | **16.8×** |
| 500 | 2,356.9 ms | 154.5 ms | **15.3×** |
| 800 | 4,229.1 ms | 309.1 ms | **13.7×** |

原因：旧实现对每个 chunk 重新 embedding 并全库搜索（O(n²) 次向量化 + statSync）；新实现一次取矩阵子集做块内点积，精确重复改为单次 SQL 分组。
回归：`tests/integration/knowledge.test.ts`、`tests/regression/vnext-fixes.test.ts`。

## 5. 内存 / 磁盘（1000 chunk 语料）

| 指标 | 值 |
| --- | --- |
| Node RSS | 246.9 MB |
| SQLite 文件 | 6.60 MB |
| 向量索引文件 | 2.06 MB |
| embedding_cache 条目 | 1,000 |

> RSS 包含 Node 运行时与测试脚本本身；未做长时间泄漏观察。索引大小 ≈ 1000×512×4B = 2.05MB，符合预期。

## 6. 失败成本与超时

- 失败任务会按 attempts/max_retries 重试，重试消耗任务预算；没有退避（P3）。
- HTTP 抓取有总 deadline + socket timeout，测试覆盖“响应头已到但 body 不结束”。
- 预算耗尽会把 stop_reason 写入 run 记录，任务回退为 retrying（不留在 running）。

## 7. 限制

- 单机单次测量，未做 CPU/IO 隔离；不同设备数值会变化。
- 未测：10+ 进程并发写、磁盘写满、长时间内存增长、真实外网 RTT。
- 未对 Python legacy 做同条件重测（只保留历史数据：197 测试 42s，旧冷启动 1.5s 量级）。
